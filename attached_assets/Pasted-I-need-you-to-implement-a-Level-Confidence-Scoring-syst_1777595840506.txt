SECTION 1 — Scoring engine
Create artifacts/api-server/src/lib/levelConfidence.ts
This module exports one function: computeLevelConfidence(playerId: string): Promise<void>
It computes and upserts a level_confidence row for every level the player has attended, using this exact scoring model:
C1 — Session exposure (max 25 pts)
sessions = COUNT of attendances rows for this player at this level
days_since_last = days since most recent attendance at this level

C1_raw = 25 × ln(sessions + 1) / ln(11)
         (naturally approaches 25 as sessions → 10+, never exceeds 25)

recency_decay = e^(−0.5 × days_since_last / 180)
C1 = C1_raw × recency_decay
C2 — Peer fit rate (max 25 pts)
peer_positive = COUNT of session_feedback rows where player_id matches
                AND level matches AND fit_rating = 1
peer_total    = COUNT of session_feedback rows where player_id matches
                AND level matches

If peer_total >= 3:
  C2 = 25 × (peer_positive / peer_total)
Else:
  C2 = 12.5   ← neutral prior, not enough data
C3 — Coach assignment (max 35 pts)
coach_level = players.coach_assigned_level
coach_set_at = players.coach_level_set_at

If coach_level is null: C3 = 0

Else:
  coach_rank   = level_taxonomy.rank WHERE level = coach_assigned_level
  booking_rank = level_taxonomy.rank WHERE level = this_level
  distance     = ABS(coach_rank - booking_rank)

  base = 35 × MAX(0, 1 − 0.4 × distance)
    distance 0 → 35 pts (exact match)
    distance 1 → 21 pts
    distance 2 → 7 pts
    distance 3+ → 0 pts

  days_since_assessment = days since coach_level_set_at
  decay = e^(−0.693 × days_since_assessment / 90)
  C3 = base × decay
C4 — DUPR alignment (max 15 pts)
dupr_rating = players.dupr_rating (may be null)
dupr_updated_at = players.dupr_updated_at

If dupr_rating is null: C4 = 0

Else:
  dupr_implied_rank = ROUND(dupr_rating)
    (e.g. 3.5 → rank 4 in a 1-6 scale, map to nearest level rank)
  booking_rank = level_taxonomy.rank WHERE level = this_level

  alignment = MAX(0, 1 − ABS(dupr_implied_rank - booking_rank) / 1.0)
  base = 15 × alignment

  days_since_dupr = days since dupr_updated_at
  decay = e^(−0.693 × days_since_dupr / 60)
  C4 = base × decay
Final score and certainty
score = C1 + C2 + C3 + C4   (will be between 0 and 100)

certainty components:
  c1_cert = MIN(1.0, sessions / 10)
  c2_cert = MIN(1.0, peer_total / 5)
  c3_cert = 1.0 if coach_level assigned, else 0
  c4_cert = 0.5 if dupr_rating present, else 0

certainty = (c1_cert × 0.25) + (c2_cert × 0.30) + (c3_cert × 0.35) + (c4_cert × 0.10)
After computing, upsert into level_confidence:

player_id, level, sessions, days_since_last, peer_positive, peer_total, score, certainty, last_computed = now()
Use ON CONFLICT (player_id, level) DO UPDATE

The function should be silent — no console logs unless there's an error.
