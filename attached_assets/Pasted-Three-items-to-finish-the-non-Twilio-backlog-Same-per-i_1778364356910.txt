ITEM 1 — routes/messages.ts bulk send Twilio-before-insert fix
────────────────────────────────────────────────────────────
File: artifacts/api-server/src/routes/messages.ts

Bug: The POST /messages/bulk handler calls Twilio before the DB insert. Same pattern as the postSessionFeedback.ts fix from the last session. Use that fix as the reference implementation.

Fix shape:
  1. INSERT message row with status: "pending", twilio_sid: null, sent_at: null. Get back the row id.
  2. If INSERT fails: log, increment failure counter, continue to next recipient. Twilio never called.

  5. Per-recipient try/catch wraps each iteration. Single failure doesn't abort the batch.
