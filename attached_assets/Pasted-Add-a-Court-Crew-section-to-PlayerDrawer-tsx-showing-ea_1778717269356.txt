PHASE 3 — BUILD THE COURT CREW SECTION
═══════════════════════════════════════════

FILE TO EDIT: artifacts/dashboard/src/components/PlayerDrawer.tsx
DO NOT EDIT any other file unless a type needs to be added to types.ts.

STEP A — Add the BuddyRow interface
If BuddyRow doesn't exist in types.ts, add it at the top of PlayerDrawer.tsx:

  interface BuddyRow {
    player_id: string;
    name: string;
    shared_sessions: number;
    last_shared_at: string | null;
  }

STEP B — Add state
Next to the existing level_confidence state declarations, add:

  const [buddies, setBuddies] = useState<BuddyRow[]>([]);
  const [buddiesLoading, setBuddiesLoading] = useState(false);

STEP C — Fetch buddies in the existing playerId useEffect
In the same useEffect that fetches level_confidence:
- In the reset block (where !playerId clears state), add: setBuddies([]);
- In the fetch block, fire the buddy fetch IN PARALLEL with the existing fetches — do not make it sequential.

Fetch pattern:
  setBuddiesLoading(true);
  fetch(`/api/social-graph/player/${playerId}/buddies`)
    .then(r => r.ok ? r.json() : { buddies: [] })
    .then(data => setBuddies(data.buddies ?? []))
    .catch(() => setBuddies([]))
    .finally(() => setBuddiesLoading(false));

STEP D — Render the Court Crew section
Place the Court Crew section DIRECTLY BELOW the level confidence section in the JSX.

Match the visual style of the adjacent sections exactly:
- Section header: same font size, weight, color, margin as neighboring section headers
- Sub-label when data is present: small muted text reading "Players with 3+ shared sessions"
- Dark card aesthetic: bg #0f1117, border #30363d, primary text #e6edf3, muted text #8b949e, accent #E8A838

Loading state:
  Show "Loading..." in muted text while buddiesLoading is true

Empty state (buddies.length === 0 and !buddiesLoading):
  Show: "No regular playing partners identified yet" in muted text (#8b949e)

Populated state — show top 5 buddies only (API returns them sorted by shared_sessions DESC):
  Each row layout:
    Left side: buddy name (primary text, normal weight)
              below name: "Last played {relativeTime(last_shared_at)}" in small muted text
              (if last_shared_at is null, omit the "last played" line)
    Right side: "{shared_sessions} sessions" in monospace muted text

  Row spacing: compact — same density as the level confidence rows above
  No interactive elements — read-only display
