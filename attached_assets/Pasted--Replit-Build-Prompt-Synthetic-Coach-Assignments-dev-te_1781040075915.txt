## STEP 1 — Seed script: `api-server/src/scripts/seedSyntheticCoachLevels.ts`

Runnable via `tsx`. Dry-run by default; `--apply` to write.

Logic:
1. Load taxonomy via `loadTaxonomy` and build each player's resolved timeline via `buildPlayerRungTimeline` (reuse `lib/curriculumFlow.ts` — do not duplicate resolution logic).
2. Eligible players: ≥1 resolved attendance AND `coach_assigned_level IS NULL`. (Skip the 7 real assignments; skip players with no resolved timeline.)
3. Baseline rank per player = modal rank of their resolved attendances (ties → most recent sustained rank).
4. Deterministic assignment via a simple hash of `player_id` (e.g. sum of char codes mod 100) mapped to buckets:
   - 0–69 → coach level = baseline rank (aligned)
   - 70–84 → baseline − 1, floor at rank 1 (synthetic "deluded": booking above coach level)
   - 85–94 → baseline + 1, ceiling at max rank (synthetic "ready to advance")
   - 95–99 → skip (leave unassigned)
5. `assigned_at`: backdate deterministically 30–180 days using the same hash (e.g. 30 + hash % 151 days ago) so stall/daysAtRank math gets variety.
6. On `--apply`, per player (batch the writes):
   - UPDATE `players.coach_assigned_level` to the level name for the chosen rank
   - INSERT into `level_history`: from_level NULL, to_level = chosen level, ranks accordingly, `source = 'synthetic'`, `assigned_at` = backdated value, `note = 'SYNTHETIC dev seed — derived from modal booking rank, bucket=<aligned|deluded|ready>'`
7. Idempotent: if a player already has a `level_history` row with `source='synthetic'`, skip them entirely.

Dry-run output: total eligible, bucket counts (aligned / deluded / ready / skipped), 10 sample rows (player_id prefix, modal rank, assigned level, bucket, backdated date), and a confirmation that the 7 real assignments were excluded.

## STEP 2 — Wipe script: `api-server/src/scripts/wipeSyntheticCoachLevels.ts`

Dry-run by default; `--apply` to write. Logic:
1. Fetch all `level_history` rows where `source = 'synthetic'`.
2. For each affected player: set `players.coach_assigned_level = NULL` **only if** its current value still equals the synthetic `to_level` (guard: a real coach may have reassigned since seeding — never null a newer real value).
3. Delete the synthetic `level_history` rows.
4. Dry-run prints: rows to delete, players to null, players protected by the guard.
