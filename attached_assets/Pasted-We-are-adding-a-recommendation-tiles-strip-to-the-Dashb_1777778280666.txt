We are adding a recommendation tiles strip to the Dashboard 
in Pulse. The goal is to make the dashboard feel like Google 
Ads or a smart command center — it tells you exactly what 
to do and takes you there in one click. No more hunting 
through pages to find what needs attention.

The tiles sit ABOVE the existing stat strip, below the 
briefing banner. They show 4 tiles at a time. Users can 
scroll through more with arrow buttons. Tiles can be 
dismissed and resurface after 48 hours (persisted in 
localStorage).

--- PART 2: DISMISSAL LOGIC ---

On mount, load dismissed recommendations from localStorage:
const DISMISS_KEY = 'pulse_dismissed_recs'

Type:
{ [recId: string]: number }  // recId → timestamp dismissed

function isDismissed(id: string): boolean {
  const dismissed = JSON.parse(
    localStorage.getItem(DISMISS_KEY) || '{}'
  );
  const ts = dismissed[id];
  if (!ts) return false;
  // Resurface after 48 hours
  return Date.now() - ts < 48 * 60 * 60 * 1000;
}

function dismissRec(id: string): void {
  const dismissed = JSON.parse(
    localStorage.getItem(DISMISS_KEY) || '{}'
  );
  dismissed[id] = Date.now();
  localStorage.setItem(DISMISS_KEY, JSON.stringify(dismissed));
}

Add state: const [dismissedIds, setDismissedIds] = useState
  Record<string, number>>({})

Load on mount:
useEffect(() => {
  const stored = localStorage.getItem('pulse_dismissed_recs');
  if (stored) setDismissedIds(JSON.parse(stored));
}, []);

Filter recommendations: const visibleRecs = recommendations
  .filter(r => !isDismissed(r.id));

On dismiss click:
1. Call dismissRec(rec.id)
2. Update dismissedIds state to trigger re-render
3. Animate tile out (opacity 0, width 0 over 200ms)
