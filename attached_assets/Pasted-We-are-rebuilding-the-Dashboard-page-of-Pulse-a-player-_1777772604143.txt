We are rebuilding the Dashboard page of Pulse — a player retention 
platform for pickleball clubs. Pulse helps club owners and coaches 
answer one question every time they open the app: "What needs my 
attention today?" The current dashboard is a spreadsheet — a full 
player table that overwhelms the user immediately. We are replacing 
it with a true command center: visual, scannable, action-oriented.

The target users are club owners and coaches — not engineers. They 
open this on a laptop between lessons or before a shift. They need 
to understand the health of their club and take action in under 
10 seconds. Every element on this page must earn its place by 
answering a question they actually have.

DESIGN DIRECTION:
- Full dark theme — #0f1117 sidebar, #161b22 main background, 
  #0f1117 cards/panels, #30363d borders
- Bento-style grid layout — panels of different sizes arranged 
  in a grid, not a list of equal-height rows
- AI briefing banner just below the topbar — the smartest, most 
  human part of the UI
- Amber (#E8A838) as the primary accent — active state, buttons, 
  highlights, links
- No player table anywhere on this page — that lives on /players
- Every panel has a "View All →" link that navigates to the 
  correct detail page

The briefing text is generated dynamically from real data:
- Count of pending messages in the queue
- Count of lapsing players
- Name of the most urgent player (longest time since last visit 
  among lapsing/dormant) + how many others

Example output:
"You have [12 messages ready to send] and [50 players drifting] 
this week. [Carlota Digon] and 4 others haven't been back in 
3+ weeks — worth a nudge today."

Build this as a pure computed string from existing state:
- messages.length → pending queue count
- players filtered to lapsing/dormant → drifting count  
- Sort lapsing/dormant by last_visit_date ascending → most urgent
- "X and Y others" phrasing when count > 1, just "X" when count = 1
- If no lapsing players: "Everything looks good — no players 
  need attention right now."
- If no pending messages: omit that sentence

--- PROGRESS INDICATOR COMPONENT ---

Create a small inline ProgressBar component at the top of 
Dashboard.tsx (above the main export):

function ProgressBar({ active }: { active: boolean }) {
  return (
    <div style={{
      height: 2,
      background: active ? '#E8A838' : 'transparent',
      borderRadius: 1,
      marginTop: 2,
      width: active ? '100%' : '0%',
      transition: active ? 'none' : 'width 0s',
      animation: active ? 'progressFill 20s linear forwards' : 'none',
    }} />
  );
}

Add to CSS in index.css or as a style tag:
@keyframes progressFill {
  from { width: 0% }
  to { width: 100% }
}

Use this under every "Send Outreach" and "Send" button 
while the action is in loading state.
