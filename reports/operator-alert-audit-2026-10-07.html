Implemented controls

  • One renewable background-worker lease owns all schedulers. A contender remains API-only standby. Every job lease must belong to that global owner, fencing old anonymous-owner worker binaries.
  • Worker registry: unique instance UUID, PID, host, process start time, environment, configured job flag, role, and heartbeat. Lease ownership—not a stale registry role—determines the active holder.
  • Durable execution journal: job, run UUID, sender identity, start/finish times and result. Existing per-job leases remain in place.
  • One shared incident state per stable condition, with atomic claims and a unique incident/phase constraint. The API and watchdog observe the same kill-switch condition; the database rechecks the actual club state.
  • One alert submission on incident opening, no periodic re-alerts, and one RESOLVED submission on clear. Recurrence opens a new incident. Existing observed pause state is carried forward without replaying its notification.
  • Every alert event records its sender and producer source, condition, phase, claim time, provider SID and submission state. Claims are committed before Twilio. Failed or ambiguous submissions are reserved for reconciliation, not automatically retried.

Verification and operational limits

Isolated PostgreSQL tests exercise six concurrent claims, a single recovery, recurrence, singleton contention/takeover, legacy-owner fencing, stale kill-switch snapshots, legacy notification carry-forward and denied anonymous access. Offline tests cover incident send suppression, ambiguous provider submission, worker leadership gating, approval protections and publishing schema checks. Tests use synthetic records and fake alert transport, not live player sends.

At-most-one provider submission is enforced per incident phase. Exactly-once external SMS delivery cannot be atomically guaranteed with a separate database and Twilio: a crash after claim but before submission can leave an unsent claim, and ambiguous provider acceptance must be reconciled before any manual retry.
